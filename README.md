# Calculatrice Flask

**TP3 du LOG3000**

**Groupe 5 : Ameli Velasco Duran et Mohammed Iich**

## Objectif

Application web de calculatrice simple construite avec Flask. L'utilisateur saisit une
opération entre deux nombres (`+`, `-`, `*`, `/`) au moyen d'un clavier à l'écran, et le
serveur calcule puis affiche le résultat.

Ce dépôt sert à structurer le projet : documentation du code, tests, suivi des bogues
avec les issues GitHub et corrections sur des branches dédiées.

## Prérequis

- Python 3.9 ou plus récent
- pip
- Git

## Installation

```bash
git clone https://github.com/amelivelasco/LOG3000-TP3.git
cd LOG3000-TP3
python -m venv .venv
source .venv/bin/activate        # Windows : .venv\Scripts\activate
pip install -r requirements.txt
```

## Lancement

```bash
python app.py
```

Ouvrir ensuite http://127.0.0.1:5000 dans un navigateur.
